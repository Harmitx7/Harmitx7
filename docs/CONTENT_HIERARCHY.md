## 2. Three-Tier Information Architecture

### Tier 1: Immediate Authority & Focal Anchors (First 3 Seconds)
- **Goal**: Establish elite competence, active shipping, and immediate credibility.
- **Key Elements**:
  - Full-width Hero Banner (`assets/hero.svg`) with celestial physics and location coordinates.
  - Social Dock (LinkedIn, GitHub, Portfolio, npm `tribunal-kit`).
  - Active Telemetry Ticker (`assets/status-bar.svg`): Proves the account is actively shipping and hackathon-winning.

### Tier 2: Core Engineering Evidence (Seconds 3 to 8)
- **Goal**: Provide tangible proof of software craftsmanship and architectural breadth.
- **Key Elements**:
  - Featured Project Dossiers (2x2 Grid): Highlighting flagship systems with clear domains and terminal quick starts.
  - Language Polyglot Spectrum (`languages.svg`): Concrete proof of multi-language fluency (JS, Python, TS, Java, Rust).
  - Development Metrics HUD (`metrics-hud.svg`): Verified repository and star telemetry without third-party badge noise.

### Tier 3: Technical Deep Dive & System Specification (Seconds 8+)
- **Goal**: Satisfy rigorous architectural evaluation by senior engineers and hiring managers.
- **Key Elements**:
  - Developer Console Manifest (`terminal-boot.svg`): Syntax-highlighted JSON specifying multi-agent architecture and 0% hallucination guarantees.
  - 4-Tier Skill Architecture Matrix (`skill-tree.svg`): 26 categorized modules.
  - Architectural Principles Table: Engineering mechanisms and impact metrics.
  - Archived Quests (`<details>` block): Historical track record of production systems.
  - Coordinate Footer (`assets/footer.svg`): Final geographic and institutional sign-off.

## 3. Cognitive Load Budget & Anti-Fatigue Rules

1. **Controlled Negative Space**: Every major SVG block is cushioned with `<br/>` spacing to prevent visual crowding.
2. **Tabular Numerals Everywhere**: Numbers never cause layout shift or optical vibration.
3. **Zero Decorative Slop**: Every visual element (crosshair, coordinate, ring, beacon) corresponds directly to an audited fact or engineering principle.
4. **Self-Contained Dark Surfaces**: Ensures identical contrast regardless of whether the viewer is using GitHub in light or dark mode.
